# Latenite Theme
[English](README.md) | [简体中文](README.zh-CN.md)

## Overview

Latenite is a dark VS Code theme featuring a **black-purple** color palette with **low saturation** and **dimmed syntax highlighting**, primarily designed for late-night coding sessions.Also it's a purely vibe-coded.

## How it was created

This theme was generated using [Yeoman](https://yeoman.io/) and the [VS Code Extension Generator](https://www.npmjs.com/package/generator-code), which provides a scaffolded structure for building custom themes.

## Design Philosophy

- **Dark, low-saturation palette**: Syntax highlighting colors are intentionally dimmed to match the brightness level of the primary text color, reducing eye strain during prolonged use.
- **Black-purple accent**: The primary accent color is `#7B68EE` (MediumSlateBlue), used sparingly for active elements and focus states.
- **Personal preference driven**: This theme is primarily tailored for my own workflow and preferences. It is not intended to be a general-purpose theme for all users.

## Supported Language Environments

This theme is primarily tested and optimized for the following languages:

- **C** / **C++**
- **Python**
- **Markdown**
- **Plain text (TXT)**

While it may work reasonably well in other environments, **no guarantees** are made regarding readability or visual coherence in other languages (e.g., Java, JavaScript, Rust, etc.).

## Installation

### Option 1: GitHub Release (Manual)

1. Download the latest `.vsix` file from the [Releases](https://github.com/rorangeeee/latenite/releases) page.
2. Open VS Code.
3. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) to open the Command Palette.
4. Run `Extensions: Install from VSIX...`.
5. Select the downloaded `.vsix` file.

### Option 2: VS Code Marketplace

*(If published)*

1. Open the Extensions view in VS Code (`Ctrl+Shift+X`).
2. Search for `Latenite`.
3. Click **Install**.
