# Change Log

All notable changes to the "latenite" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [0.1.1]

- Retuned **latenite dawn** to a softer taro lilac: paler, less saturated surfaces (`#CEBCD9` editor, `#BDA3CE` chrome, `#DCD2E3` widgets) with the whole background ramp rebuilt around them.

## [0.1.0]

- Added **latenite dawn**, a light counterpart built on the same palette: lavender paper (`#C6ACE0`) with deep violet ink and an `#40009E` accent.

## [0.0.1]

- Initial release
